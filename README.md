# leetcode-sql-50

Repository of LeetCode SQL practice problems and solutions.

Structure
- `MYSQL/` — collection of `.sql` solution files, named with problem IDs and titles.

How to use
- Open any `.sql` file in your SQL editor or VS Code to read the solution.
- To run a query locally, execute the file against a MySQL-compatible server, for example:

```sh
mysql -u <user> -p <database> < MYSQL/1321_Restaurant_Growth.sql
```

Contributing
- Add new solution files to the `MYSQL/` folder following the naming convention `NNNN_Title.sql`.
- Commit your changes and open a pull request.
